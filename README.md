# 神经外科模拟手术套件

这是三个面向 3D Slicer 的神经外科模拟脚本模块，统一归类在 **神经外科模拟手术套件** 下，作者为 **myz**。

本套件用于教学和研究性规划演示，未经临床验证，不是医疗器械或临床决策工具。造瘘与牵拉结果是定性模拟，不代表安全边界或精确生物力学预测；颅骨模块会输出定量几何测量值，但其准确性取决于原始影像、体素间距和分割质量。

## 模块列表

| 文件 | 模块名称 | 主要功能 |
| --- | --- | --- |
| `BrainFistulaVRSim.py` | 脑实质造瘘模拟（体积渲染） | 用两点通道模拟脑实质造瘘/手术通道，并把通道内 MRI 体素生成掩膜，通过体积渲染显示为透明隧道 |
| `BrainRetractionSim2.py` | 脑牵拉模拟2.0 | 使用 PBD 约束对脑表面模型进行压板牵拉形变模拟 |
| `CraniectomySim.py` | 颅骨切除模拟 | 在 CT 体积渲染场景中标记并切除颅骨区域，测量体积、OBB、Feret 直径等指标并导出 CSV |

## 环境要求

- **3D Slicer 5.12.x**（目标与开发版本；公开发布前请在干净安装中完成下文的 GUI 冒烟测试）
- 代码不依赖 Windows 专属 API，但尚未在 Linux 和 macOS 上完成验证。
- 完整版 3D Slicer，包含以下内置模块：
  - Segment Editor / Segmentations
  - Volume Rendering
  - Segment Statistics
- 在 3D Slicer 内置 Python 环境中不需要额外安装依赖；脚本只使用 Slicer 自带的 `numpy`、`vtk`、`qt`、`ctk`、`slicer`。

## 安装方法

1. 下载本仓库并解压，或把三个 `.py` 文件复制到同一个本地文件夹，例如：

   ```text
   C:\Users\<你的用户名>\SlicerModules\NeurosurgerySimSuite
   ```

2. 打开 3D Slicer。

3. 进入菜单：

   ```text
   Edit → Application Settings → Modules
   ```

4. 在 **Additional module paths** 中点击 **Add**，选择**直接包含三个 `.py` 文件**的文件夹，不要选择下载后多出来的外层目录。

5. 重启 3D Slicer。

6. 在模块搜索框或模块列表中，应能在 **神经外科模拟手术套件** 分类下看到三个模块：

   - 脑实质造瘘模拟（体积渲染）
   - 脑牵拉模拟2.0
   - 颅骨切除模拟

如果模块没有出现，先确认 Additional module paths 指向正确目录，再打开 **View → Error Log** 查看加载错误。不要使用系统 Python 直接运行这些文件；它们必须由 3D Slicer 加载。

## 使用说明

### 1. BrainFistulaVRSim — 脑实质造瘘模拟

适用场景：观察脑实质内造瘘通道的路径、方向和形态。

操作步骤：

1. 选择 MRI 体积。
2. 点击 **新建两点通道**。
3. 在 3D 视图中拖动 **入口点** 和 **靶点**，调整通道方向和深度。
4. 选择通道形状，并调整入口/出口半径、椭圆度、截面旋转角、入口延伸量。
5. 点击 **生成掩膜体积并打开 VR**。
6. 3D 视图中会显示脑实质内的透明隧道。
7. 需要时勾选 **实时更新**，拖动两点或调整参数会自动刷新。
8. 点击 **恢复原始体积** 可移除掩膜体积并恢复原始 MRI 显示。

特点：

- 不修改原始 MRI，结果生成在新的掩膜体积节点上。
- 支持管状、椭圆管、锥形口小底大、椭圆锥形。
- 通道表面由 NumPy 向量化生成；实时更新只检查通道附近的体素子块，并原地恢复上一帧体素。
- “恢复原始体积”会从当前场景删除本模块生成的掩膜体积，并恢复原体积显示；不会改写磁盘上的 MRI 文件。
- 输入应为具有正确空间几何的单通道标量 MRI。通道仅用于路径形态演示，不能据此判断组织安全距离。

### 2. BrainRetractionSim2 — 脑牵拉模拟

适用场景：模拟脑压板牵拉导致的脑组织近似形变。

操作步骤：

1. 选择脑表面模型或 Segmentation 节点。
2. 点击 **生成模拟网格**。
3. 点击 **新建压板平面**。
4. 在 3D 视图中拖动或旋转压板平面，设置压入方向和位置。
5. 调整压板宽度、长度、压入深度、PBD 迭代次数、边长保持、体积保持和影响半径。
6. 点击 **开始形变** 进行模拟。
7. 可勾选 **按位移染色** 查看变形幅度；点击 **复位到初始形态** 恢复。

特点：

- 基于 PBD 约束的软组织近似模拟。
- 不修改原始模型/分割。
- 拖动压板时支持实时预览。
- PBD 顶点约束使用批量累加，位移标量数组在帧间复用，减少实时交互中的 Python 和 VTK 分配。
- 这是封闭表面网格上的 PBD 近似，不是体积有限元模型；未模拟材料各向异性、血管/脑室接触或组织自碰撞。

### 3. CraniectomySim — 颅骨切除模拟

适用场景：模拟去骨瓣减压、颅底入路骨质切除等，并测量切除范围。

操作步骤：

1. 选择输入 CT Volume。
2. 新建或选择 Segmentation 和 Segment。
3. 使用 **阈值分割写入 Segment** 或 **打开 Segment Editor 进行标记**，标记要切除的颅骨区域。
4. 一次性查看时，点击 **执行切除并渲染（一次性）**；需要边画边看时，点击 **开启实时切除预览**，模块会跳转到 Segment Editor，绘制或擦除后自动刷新。
5. 系统生成新的切除后 Volume，并自动打开体渲染。关闭实时预览后，输出 Volume 会保留在场景中。
6. 点击 **测量当前 Segment** 或 **测量全部 Segments**，查看体积、表面积、长宽高、Feret 直径、中心坐标。
7. 点击 **导出 CSV** 保存测量结果。
8. 可点击 **一键显示已切除骨质模型** 单独查看切除骨质。

特点：

- 不修改原始 CT，结果生成在新的 Volume 节点上。
- 支持实时切除预览。
- 支持多 Segment 合并切除。
- 测量结果包含体积、表面积、OBB 长宽高、Feret 最大径等。
- “测量全部 Segments”只运行一次 Segment Statistics；实时切除只写入发生变化的体素。
- 阈值分割得到的是候选骨组织，不等于待切除范围；请在 Segment Editor 中确认并修正。测量结果使用毫米、平方毫米、立方毫米/毫升和 RAS 坐标，受 CT 层厚、空间几何与分割质量影响。

## 性能优化与基准

本版本主要针对拖动通道、PBD 求解、实时切除和批量测量四条高频路径进行了优化：

- `BrainFistulaVRSim`：通道网格顶点和三角面改为向量化生成；体素候选框按真实轴向延伸范围裁剪，并移除大体积齐次坐标数组。
- `BrainRetractionSim2`：PBD 边长、面积和最大拉伸约束改为批量顶点累加；固定点选择使用线性期望复杂度的分区选择；显示层复用位移数组。
- `CraniectomySim`：全部 Segment 统计从“每段完整计算一次”改为“一次计算、逐段格式化”；实时掩膜复用输入/输出数组，并仅更新状态变化的体素。

以下为开发阶段的独立 NumPy 核心快速抽样，运行环境为外部 Python 3.12.13、NumPy 2.3.5，并非 Slicer 5.12.2 的内置 Python。网格生成和 PBD 各记录一次，点判定取 5 次中的较快值；这些数字只用于检查优化方向，不是正式、可复现的性能报告，也不代表 3D Slicer 完整界面帧率。

| 测试 | 优化前 | 优化后 | 加速比 |
| --- | ---: | ---: | ---: |
| 生成造瘘通道网格 1000 次（默认 20 环 × 28 点） | 2.323 s | 0.234 s | 9.9× |
| 判定 50 万个点是否位于通道内 | 0.0327 s | 0.0179 s | 1.8× |
| 牵拉 PBD：4000 点、约 2.4 万边、10 轮 | 0.0839 s | 0.0533 s | 1.6× |

实际速度还会受到模型规模、体积尺寸、显卡体积渲染、Segment 数量和 Slicer 版本影响。建议发布前再用你的代表性病例数据记录端到端耗时。
