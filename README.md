# 神经外科模拟手术套件

这是一个供 3D Slicer 使用的神经外科模拟脚本合集，包含脑实质造瘘、脑牵拉和颅骨切除三个模块。模块统一归在 3D Slicer 的 `神经外科模拟手术套件` 分类下，作者为 `myz`。

这些脚本主要用于教学和研究中的规划演示，尚未经过临床验证。造瘘与牵拉结果只能用于定性观察，不能当作安全边界或精确的生物力学预测。颅骨模块可以输出几何测量值，但结果会受到原始影像、体素间距和分割质量的影响。

## 包含的模块

| 文件 | 在 Slicer 中显示的名称 | 用途 |
| --- | --- | --- |
| `BrainFistulaVRSim.py` | 脑实质造瘘模拟（体积渲染） | 用入口点和靶点建立造瘘通道，并通过体积渲染显示透明隧道 |
| `BrainRetractionSim2.py` | 脑牵拉模拟2.0 | 使用 PBD 约束模拟压板牵拉造成的脑表面形变 |
| `CraniectomySim.py` | 颅骨切除模拟 | 在 CT 中标记并切除颅骨区域，测量切除范围并导出 CSV |

## 运行环境

- 按 3D Slicer 5.12.x 开发。正式使用或发布前，建议在干净安装的相同版本中再走一遍基本流程。
- 需要完整版 3D Slicer，以及其中的 Segment Editor、Segmentations、Volume Rendering 和 Segment Statistics 模块。
- 不需要另外安装 Python 包。代码只使用 Slicer 自带的 `numpy`、`vtk`、`qt`、`ctk` 和 `slicer`。
- 代码没有使用 Windows 专属 API，但目前尚未在 Linux 和 macOS 上验证。

## 安装

1. 下载并解压仓库，或者把三个 `.py` 文件放到同一个目录，例如：

   ```text
   C:\Users\<你的用户名>\SlicerModules\NeurosurgerySimSuite
   ```

2. 打开 3D Slicer，进入 `Edit → Application Settings → Modules`。
3. 在 `Additional module paths` 中点击 `Add`，选择直接包含三个 `.py` 文件的目录。不要选下载后套在外面的那一层文件夹。
4. 重启 3D Slicer。
5. 在模块搜索框中搜索模块名称，或者在 `神经外科模拟手术套件` 分类下打开它们。

如果模块没有出现，先检查 `Additional module paths` 是否指向正确目录，再到 `View → Error Log` 查看加载错误。这些文件需要由 3D Slicer 加载，不能用系统 Python 直接运行。

## 使用方法

### BrainFistulaVRSim：脑实质造瘘模拟

这个模块用于查看脑实质内通道的路径、方向和形态。

1. 选择 MRI 体积，点击 `新建两点通道`。
2. 在 3D 视图中拖动入口点和靶点，确定通道方向与深度。
3. 选择通道形状，再调整入口半径、出口半径、椭圆度、截面旋转角和入口延伸量。
4. 点击 `生成掩膜体积并打开 VR`，在 3D 视图中查看透明隧道。
5. 需要边调整边查看时，勾选 `实时更新`。拖动控制点或修改参数后，结果会自动刷新。
6. 点击 `恢复原始体积` 可删除本模块生成的掩膜节点，并恢复原 MRI 的显示。

模块不会改动原始 MRI，也不会改写磁盘上的影像文件。它支持管状、椭圆管、锥形口小底大和椭圆锥形通道。

输入应为具有正确空间几何的单通道标量 MRI。通道只用于路径和形态演示，不能据此判断组织安全距离。

### BrainRetractionSim2：脑牵拉模拟

这个模块用封闭表面网格近似模拟脑压板牵拉造成的形变。

1. 选择脑表面模型或 Segmentation 节点，点击 `生成模拟网格`。
2. 点击 `新建压板平面`，在 3D 视图中移动或旋转压板，设置位置和压入方向。
3. 调整压板宽度、长度、压入深度、PBD 迭代次数、边长保持、体积保持和影响半径。
4. 点击 `开始形变`。
5. 勾选 `按位移染色` 可以查看各处位移大小；点击 `复位到初始形态` 可恢复模型。

模拟结果保存在单独的模型中，不会修改原始模型或分割。拖动压板时可以实时预览。

这里使用的是 PBD 表面近似，不是体积有限元模型。材料各向异性、血管和脑室接触、组织自碰撞等因素没有纳入模拟。

### CraniectomySim：颅骨切除模拟

这个模块用于演示去骨瓣减压、颅底入路骨质切除等操作，并测量切除范围。

1. 选择输入 CT Volume，新建或选择 Segmentation 和 Segment。
2. 使用 `阈值分割写入 Segment` 生成候选骨组织，或者打开 Segment Editor 手工标记需要切除的区域。
3. 只需查看一次结果时，点击 `执行切除并渲染（一次性）`。
4. 需要边画边看时，点击 `开启实时切除预览`。模块会进入 Segment Editor，绘制或擦除后自动刷新体积渲染。
5. 点击 `测量当前 Segment` 或 `测量全部 Segments`，查看体积、表面积、OBB 长宽高、Feret 最大径和中心坐标。
6. 点击 `导出 CSV` 保存测量结果。需要单独查看切除骨质时，可点击 `一键显示已切除骨质模型`。

切除结果写入新的 Volume 节点，原始 CT 不会被修改。关闭实时预览后，输出 Volume 仍保留在场景中。模块也支持合并多个 Segment 进行切除。

阈值分割得到的只是候选骨组织，仍需在 Segment Editor 中确认和修正。测量单位包括毫米、平方毫米、立方毫米或毫升，坐标使用 RAS。CT 层厚、空间几何和分割质量都会影响结果。
